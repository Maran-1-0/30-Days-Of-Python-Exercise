# 6) Area and Perimeter of a Rectangle
## Code
```python
l = int(input("Enter length: "))
b = int(input("Enter width: "))

area  = l*b
perimeter = 2*(l+b)

print(f"The rectangle area is {area}cm2 and perimetre is {perimeter}cm.")
```

# 7) Area and Circumference of a Circle
## Code
```python
r = float(input("Enter radius os the circle: "))
pi = 3.14

area = 2*pi*r**2
circumference = 2*pi*r

print(f"The area and circumference of the circle is {area:.2f}cm2 and {circumference:.2f}cm.")
```
